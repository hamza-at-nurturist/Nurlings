# Tasks

> Scope: the web, desktop and mobile UIs **and** what a dedicated client server shows and does:
> account emails, chat-channel text, update messages, model/billing blurbs, self-update off, our
> own images, and the bundle-id support the API needs. Not in scope: model prompts, bot

> `rakazo://` scheme, Expo slug, desktop `appId` and `executableName` stay. Disable, never
> re-point, every updater. One small commit per task or tight group; "Verify" is what proves it.
